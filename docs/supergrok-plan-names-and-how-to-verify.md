## 30 秒结论

- SuperGrok 的**档位名称和价格近期多次变化**，不同整理里的说法不一致——有的只提标准版和 Heavy，有的还列出 Lite、Plus 等更多档位。
- **SuperGrok 和 X Premium 不是一回事**：前者是 Grok 自己的订阅，后者是 X 平台的会员体系，它们的关系和权益近期也在调整。
- **订阅和 xAI API 是分开的**：据多家公开整理，SuperGrok 不含 API 额度。
- 所以下单前最可靠的做法，是用下面的清单，直接对着**购买时显示的官方页面**核对。

## 下单前的 8 项核对清单

不论在哪里买，都对着**结账页面实际显示的内容**核对：

1. **档位名称**：页面上写的完整名称是什么，和你想买的是否一致；
2. **计费周期**：月付、季付还是年付，到期后是否自动续费；
3. **价格与币种**：含不含税，手机应用内价格可能与网页不同；
4. **包含什么**：用量、模型、功能，页面写的是绝对数字还是相对倍数；
5. **是否含 X Premium 权益**：如果含，是哪一档；
6. **账号标识**：需要你提供的是公开的账号名 / ID，还是登录凭据（后者一律不能给，见 [账号 ID 与账号安全](../README.md)）；
7. **订阅与 API**：确认购买的是会员，而不是 API 额度；
8. **取消和退款规则**：订阅渠道（官方、应用商店、第三方）不同，规则也不同。

## 怎么确认购买后是否生效

- 到你的 Grok / X 账号的订阅设置里看**当前方案的名称和到期日**；
- 不要只看订单状态或收据邮件；
- 个别功能可能因地区或灰度未立即出现，先退出重登；
- 方案名称和你购买的不一致时，保留截图，联系收款方。

## 常见问题

### 为什么每篇文章写的 SuperGrok 档位都不一样？
因为官方的档位和价格在变，而很多整理没有标明核验日期和来源。核对时只信官方页面。

### SuperGrok 含 API 额度吗？
据多家公开整理，不含；API 需要在 xAI 的开发者控制台单独开通并按 token 付费。

### 我不用 X，该买 SuperGrok 还是 X Premium？
如果你只想要 Grok 的功能，一般更应该从 SuperGrok 这一类订阅看起；如果你本来就在用 X，再看会员体系里的附带权益。具体以官方页面为准。
